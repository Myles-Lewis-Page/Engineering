An Excel workbook used to spec, engineer, and generate pick lists for garage/commercial door installations. A single job is entered once on the FAB sheet, and the workbook automatically calculates all required parts, track sizes, spring specifications, hinge counts, hardware, and field assembly instructions across the Engineering and Field sheets.

Overview
This tool is designed for door fabrication shops and field installation crews. It eliminates manual calculation and part lookup by automating:

Track and horizontal angle selection based on door height/width
Spring wire gauge, diameter, turns, and length calculations
Hinge type and quantity determination per section count
Low headroom (LHR) component detection and substitution
Strut sizing and quantity
Cable, drum, bearing plate, and fixture selection
A complete field-ready parts summary for installers

All data flows from a single data-entry sheet (FAB) — no values need to be entered twice.
